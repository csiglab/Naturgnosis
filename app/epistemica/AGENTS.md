# AGENTS.md — Epistemic Space

## Purpose

The space of episteme: disciplines, fields, and bodies of knowledge that deep study and mastery can
pursue — mapped as a navigable graph. Currently a **scaffold** (empty dataset) copied from the
Social Space app. Spec: `spec/epistemica/README.md`.

## Layout

- `web/index.html` — explorer; `web/edit.html` — editor (`const DATASET = 'epistemica'`).
- `data/data.json` — server-written mirror, initially generated by `bin/import_*.py` from `import/`.
- `import/` — raw source exports (archival; never edit).

## Commands

```sh
python bin/sync.py                    # serve (dataset=epistemica is auto-discovered)
python bin/import_epistemica.py         # regenerate data.json from import/ (before editor work!)
curl /api/graph?dataset=epistemica    # nodes (empty until populated)
```

## Invariants

- Dataset id is `epistemica`.
- Distinct from the separate **Epistecnica** repository (personal pursuit of mastery for @dbremont):
  this module maps the episteme itself; personal curricula stay in that other repo.
- The web app is a copy of the social one: propagate shared fixes from the other graph modules.
