# AGENTS.md — Technique Space

## Purpose

Fine-grained technique graph: technical artifacts, engineering principles, methods, competences,
standards — the layer beneath the Production Space. Currently a **scaffold** (empty dataset) copied
from the Social Space app. Spec: `spec/technique/README.md`.

## Layout

- `web/index.html` — explorer; `web/edit.html` — editor (`const DATASET = 'technique'`).
- `data/data.json` — server-written mirror, initially generated by `bin/import_*.py` from `import/`.
- `import/` — raw source exports (archival; never edit).

## Commands

```sh
python bin/sync.py                    # serve (dataset=technique is auto-discovered)
python bin/import_technique.py         # regenerate data.json from import/ (before editor work!)
curl /api/graph?dataset=technique     # nodes (empty until populated)
```

## Invariants

- Dataset id is `technique`.
- Do not confuse with Production Space (`app/production/`): production keeps the economic shell,
  technique the technical interior.
- The web app is a copy of the social one: propagate shared fixes from the other graph modules.
