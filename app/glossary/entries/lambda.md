| **Programming Languages** | *Anonymous Functions* | Functions defined without a name, often inline | `lambda x: x+1` (Python), `x => x+1` (JS) |

| **Compilers / IR** | *Lambda Lifting* | Transforming nested functions to top-level with extra parameters | Used in GHC, ML compilers |
|  | *Lambda Forms* | Internal representation for functions in lazy evaluation | Graph reduction machines |
| **Type Theory / Formal Logic** | *Typed Lambda Calculus* | Lambda calculus with types, forming foundation of logic and proof systems | System F, λ→, λΠ, used in Coq, Agda |
| **Functional Programming** | *Lambda Expressions* | Core abstraction mechanism for pure, higher-order computation | Haskell, Scheme, Lisp |
| **AI / Logic Programming** | *Lambda Terms in Logic* | Used in symbolic AI for knowledge representation and higher-order logic | λProlog, theorem provers |
| **Big Data Processing** | *Lambda in Data Pipelines* | Used for transformations in data processing pipelines (map, reduce, etc.) | Apache Spark, PySpark |
