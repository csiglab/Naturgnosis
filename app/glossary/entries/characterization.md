**Characterization**: In mathematics, a characterization of an object is a set of conditions that, while different from the definition of the object, is logically equivalent to it. To say that “Property P characterizes object X” is to say that not only does X have property P, but that X is the only thing that has property P (i.e., P is a defining property of X). Similarly, a set of properties P is said to characterize X, when these properties distinguish X from all other objects. Even though a characterization identifies an object in a unique way, several characterizations can exist for a single object. Common mathematical expressions for a characterization of X in terms of P include “P is necessary and sufficient for X”, and “X holds if and only if P”.
