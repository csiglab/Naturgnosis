# Network Interface

The term **"network interface"** exhibits **polysemy** (multiple meanings) depending on the context in which it is used. Here are the key interpretations:

1. **Hardware Perspective** – Refers to a **network interface card (NIC)**, a physical device that connects a computer to a network, whether wired (Ethernet) or wireless (Wi-Fi).
2. **Software Perspective** – Denotes a **logical or virtual network interface**, such as `eth0`, `wlan0`, or `lo` (loopback) in Linux, representing an abstraction for network communication.
3. **Protocol Perspective** – Can mean an **interface between network layers**, defining how different layers (e.g., transport and internet layers) interact within a protocol stack.
4. **API Perspective** – Refers to **network programming interfaces** like Berkeley Sockets or Winsock, which allow applications to communicate over a network.
