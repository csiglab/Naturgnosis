| **Domain** | **Meaning of Kernel** | **Description / Example** |
| --- | --- | --- |
| **Mathematics** | **Kernel of a function** | The set of elements that a function maps to zero, e.g., in linear algebra, the **null space** of a matrix. |
| **Machine Learning** | **Kernel function** | A function that computes inner products in a higher-dimensional space without explicit transformation (e.g., **Radial Basis Function (RBF) Kernel** in SVM). |
| **Computer Science** | **Operating system kernel** | The core part of an operating system that manages hardware and system calls (e.g., **Linux kernel**). |
| **Signal Processing** | **Kernel in convolution** | A small matrix used in convolution operations for image processing (e.g., edge detection with a **Sobel kernel**). |
| **Statistics** | **Kernel density estimation (KDE)** | A non-parametric way to estimate a probability distribution from a finite sample of data. |
| **Graph Theory** | **Kernel of a directed graph** | An independent, absorbing subset of vertices in a directed graph. |
| **Linguistics** | **Kernel sentence** | A simple, basic sentence structure from which more complex sentences are derived. |
| **Food Science** | **Grain kernel** | The edible inner part of a seed, such as a **corn kernel** or **wheat kernel**. |
| **Physics** | **Kernel in nuclear physics** | The **core** or **nucleus** of an atom, especially in reference to nuclear reactions. |
| **Philosophy / Logic** | **Kernel of an idea** | The **essential core concept** or fundamental part of an argument or thought. |
