# Token

: 5
 : 5

> **Token** comes from Old English *tācen* (“sign, mark, symbol”), from Proto-Germanic *taiknam* and ultimately from Proto-Indo-European *deik-* (“to show, point out”), originally meaning a visible sign that represents or indicates something else.
> 

> A minimal *stand-in* or *signifier* that points to or encodes something else.
> 

## Term

> Which are the different uses of the term token?
> 

| **Domain** | **Use** | **Semantics** |
| --- | --- | --- |
| Linguistics | Unit of text | Represents words, punctuation, or symbols for parsing, analysis, or computation |
| CS | Lexical token | Smallest syntactic element recognized by a compiler or interpreter |
| Computer Security | Authentication Token | Encoded string representing access rights or identity |
| Economics | Digital / cryptocurrency token | Represents value, ownership, or rights in a system |
| Philosophy | Token as instance of a type | Particular occurrence that instantiates an abstract category or type |
| Other | Marker or piece | Symbolic representation tracking resources, states, or players |
| LLMs | Token | A minimal representational unit (word, subword, or character) in model input or output, used for training and inference. |
