# Conjugate

> In essence, a **conjugate** is often an “opposite” or “reflected” version of a mathematical object that maintains certain algebraic relationships with the original.
> 

## Use

| **Area** | **Object** | **Conjugate** | **Interpretation** |
| --- | --- | --- | --- |
| **Complex Number** | $a + bi (a, b ∈ ℝ)$ | $a - bi$ | Reflection across the real axis in the complex plane; product with original gives |
| **Algebra** | Element in an algebraic structure | Element obtained by an automorphism | Preserves algebraic structure while inverting certain elements; fundamental in understanding field extensions |
| **Linear Algebra** | Matrix $A$ | $A^*$ (conjugate transpose) | Obtained by transposing and taking complex conjugates of entries; defines Hermitian and unitary matrices |
| **Polynomial** | Polynomial with root α | Polynomial with conjugate roots | If α is a root, its conjugates are other roots of its minimal polynomial over the base field |
| **Group Theory** | Element h in group $G$ | $g^{⁻¹}$hg for $g ∈ G$ | Related by inner automorphism; shares properties like order; forms conjugacy classes |
| **Quaternion** | $q = a + bi + cj + dk$ | $\overline{q} = a - bi - cj - dkq=a−bi−cj−dk$ | Negates vector part while keeping scalar part; qq* = |
| **Linear Fractional Transformations** | $f(z) = (az + b)/(cz + d)$ | $f(z) = (āz + b̄)/(cz̄ + d̄)$ | Conjugating coefficients results in geometrically related transformation, often a reflection |
| **Galois Theory** | Element in field extension K/F | Images under embeddings of K into algebraic closure | Have same minimal polynomial over base field; indistinguishable from F's perspective |
| **Functional Analysis** | Function f or operator T | f̄ (complex conjugate) or T* (adjoint) | For functions: reflection across real axis; for operators: generalization of conjugate transpose |
| **Differential Equations** | Complex-valued solution | Complex conjugate solution | For equations with real coefficients, if f is a solution, so is f̄; used to construct real solutions |
