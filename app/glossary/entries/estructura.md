**Structure**: La estructura (del latín structūra) es la disposición y orden de las partes dentro de un todo. También puede entenderse como un sistema de conceptos coherentes enlazados, cuyo objetivo es precisar la esencia del objeto de estudio. La estructura es el conjunto de elementos que caracterizan un determinado ámbito de la realidad o sistema. Los elementos estructurales son permanentes y básicos, no son sujetos a consideraciones circunstanciales ni coyunturales, sino que son la esencia y la razón de ser del mismo sistema. - System / Set - Parts - Function - Relation
