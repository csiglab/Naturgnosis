# Agenda

> **Agenda** is the prioritized set of actions and initiatives ordered for collective attention and pursuit — the organization form that converts a `Strategy`'s selection into a committed doing: which objectives come first, which initiatives carry them, in which priority order, judged by which milestones.

## Formulation

### What social element type does this social instance belong to?

**Agenda belongs to the `Agenda` social element type (Action category, `Action Organization` branch, Synontic layer)** — a prioritized set existing through the shared commitment of its actors to the same ordering. It is distinct from `Strategy` (the ends/means selection it translates), from `Policy` (the course it may execute or announce), from `Program` (the coordinated set that may implement it), from `Plan` (the arrangement sequencing any one of its moves), and from `Initiative` (a launched undertaking it may spawn).

### What is this social instance?

> The prioritized doing: an objective declared, items gathered under it, a priority order fixing which comes first, a sponsor committing standing behind the order, and milestones judging whether the pursuit advances. Agendas decompose into their kinds and their anatomy; the set is the instance, the shared priority the form.

### What is the recursive instance decomposition of this social instance?

> Boundary: one organization family, decomposed at middle depth — kinds and anatomy only.
>
> Stopping rule: a row is terminal when it names an agenda kind or an anatomy element.
>
