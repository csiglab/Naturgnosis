# Strategy

> **Strategy** is the deliberate selection of ends and means over a horizon, coordinating action across agents — the guidance coordinator that fixes *what* is pursued and *how*, so that subsequent decisions (policies, plans, programs, projects) inherit direction instead of improvising it.

## Formulation

### What social element type does this social instance belong to?

**Strategy belongs to the `Strategy` social element type (Action category, `Action Guidance` branch, Normative layer)** — a recognition-constituted coordinator that orients collective doing. Its facet is normative: it warrants and constrains action without itself being the action.

It is distinct from `Policy` (the course adopted by an authority within a strategy), from `Plan` (the concrete arrangement of future actions), and from `Program` (a coordinated set of projects). A strategy selects; a policy authorizes; a plan arranges; a program executes.

### What is this social instance?

> The ends-and-means selection by which an agent binds its future doings: objectives fixed, resources committed, posture declared, and the horizon over which both are judged. Levels run from grand strategy down to functional strategy; every level decomposes into the objectives it sets, the commitments it allocates, and the reviews that revise it.

### What is the recursive instance decomposition of this social instance?

> Boundary: one guidance family, decomposed at middle depth — levels, domains, and components only.
>
> Stopping rule: a row is terminal when it names a strategy level, a strategy domain, or a strategy component.
>
> Identity: Instance Tree Path is the stable identifier of each row; every path is unique.

| `Strategy` → Strategy → Grand Strategy | Highest-level selection binding a polity's or enterprise's long-range ends to its means. |
| `Strategy` → Strategy → Grand Strategy → National Security Strategy | Polity-level selection aligning diplomatic, military, and economic means with security ends. |
| `Strategy` → Strategy → Grand Strategy → Military Strategy | Selection of military ends and means within the national posture. |
| `Strategy` → Strategy → Corporate Strategy | Enterprise-level selection of arenas, advantages, and resource commitments. |
| `Strategy` → Strategy → Corporate Strategy → Growth Strategy | Selection committing the enterprise to expansion of scale or scope. |
| `Strategy` → Strategy → Corporate Strategy → Diversification Strategy | Selection spreading the enterprise across arenas to bound risk. |
| `Strategy` → Strategy → Business Strategy | Unit-level selection of how one business competes in its arena. |
| `Strategy` → Strategy → Business Strategy → Cost Leadership Strategy | Selection competing on lowest delivered cost. |
| `Strategy` → Strategy → Business Strategy → Differentiation Strategy | Selection competing on a distinctive offer buyers reward. |
| `Strategy` → Strategy → Functional Strategy | Function-level selection aligning one capability with the business posture. |
| `Strategy` → Strategy → Functional Strategy → Marketing Strategy | Selection of segments, positioning, and channels. |
| `Strategy` → Strategy → Functional Strategy → Innovation Strategy | Selection of how the unit sources, funds, and absorbs novelty. |
| `Strategy` → Strategy → Market-Entry Strategy | Selection of mode, timing, and commitment for entering a new arena. |
| `Strategy` → Strategy → Industrial Strategy | Polity-level selection of sectors, capabilities, and instruments for economic development. |
| `Strategy` → Strategy → Electoral Strategy | Selection of coalition, message, and resource allocation for winning office. |
| `Strategy` → Strategy → `Goal` | Grouping: the ends the strategy fixes. |
| `Strategy` → Strategy → `Goal` → Strategic Objective | Desired future state the strategy commits the agent to pursue. |
| `Strategy` → Strategy → `Resource` | Grouping: the means the strategy commits. |
| `Strategy` → Strategy → `Resource` → Strategic Resource Commitment | Allocation of scarce means bound to the strategic ends. |
| `Strategy` → Strategy → `State` | Grouping: the posture snapshot the strategy declares. |
| `Strategy` → Strategy → `State` → Strategic Posture | Declared stance toward rivals, partners, and arenas at a moment. |
| `Strategy` → Strategy → `Process / Event` | Grouping: the revision by which the strategy is judged. |
| `Strategy` → Strategy → `Process / Event` → Strategic Review | Punctual occurrence reassessing ends and means against results. |
