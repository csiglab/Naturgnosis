# Technical Activity

> **Technical Activity** is the coarse bundle of granular social actions through which agents produce, sustain, and transform reality through technique — the technical-facet subtype of `Activity`: intelligence, research, development, acquisition, transfer, assimilation, adaptation, verification, demonstration, scaling, integration, standardization, commercialization, operation, maintenance, transformation.

## Formulation

### What social element type does this social instance belong to?

**Technical Activity belongs to the `Activity` social element type (Action category)** — a coarse bundle of granular technical actions performed as one situated doing. Its layer is **Ontic**: the doing exists extra-mentally. Its facet is technical.

Readable secondarily as a `Technical Element` in Technique Space (the technique as structure rather than performance); that reading is prose here, not a second root — link to Technique Space, do not duplicate. It is distinct from the artifact (the `Technical Element` it produces or uses), the actor (the unit or role performing it), and the output.

### What is this social instance?

> The technical doing-family that moves a technique along its life: from intelligence and research, through development, acquisition, transfer, assimilation, adaptation, verification, demonstration, scaling, integration, standardization, and commercialization, to operation, maintenance, and transformation. Each is a bundle of granular technical actions; recurrence (a cycle repeated over time) is typed as dynamics, not as the activity itself.

### What is the recursive instance decomposition of this social instance?

> Boundary: one technical activity family, decomposed at middle depth — the activity subtypes only.
>
> Stopping rule: a row is terminal when it names a technical activity subtype.

## QA

### What are the fundamental ways an actor can engage with a technique?

> Actors engage with **techniques** through technical activities, which extend from inquiry and creation to qualification, realization, operation, acquisition, assimilation, and mastery.

| **Family**                    | **Activity**               | **Description**                                                                                                                            | **Outcome**                                         |
| ----------------------------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------- |
| **Technical Research**        | **Exploration**            | Systematically examines the space of possible technical principles, approaches, solutions, configurations, and opportunities.              | Mapped space of technical possibilities             |
|                               | **Discovery**              | Identifies previously unknown principles, phenomena, mechanisms, relationships, or technical possibilities.                                | Newly identified technical knowledge or possibility |
|                               | **Investigation**          | Determines how a phenomenon, principle, mechanism, or technical system works.                                                              | Explanation or understanding of technical behavior  |
|                               | **Characterization**       | Determines the properties, behavior, performance, operating conditions, and limits of a technical object or phenomenon.                    | Characterized technical properties and limits       |
| **Technical Experimentation** | **Experimentation**        | Deliberately manipulates conditions or variables to generate evidence about technical behavior.                                            | Experimental evidence                               |
|                               | **Modeling**               | Constructs formal, computational, mathematical, or conceptual representations of technical phenomena or systems.                           | Technical model                                     |
|                               | **Simulation**             | Uses a model or computational environment to examine technical behavior under specified or hypothetical conditions.                        | Simulated technical evidence                        |
| **Technical Creation**        | **Invention**              | Creates a previously nonexistent technical principle, mechanism, method, device, process, or solution.                                     | New technical invention                             |
|                               | **Design**                 | Specifies the structure, components, relationships, parameters, and operating logic of a technical solution.                               | Technical design/specification                      |
|                               | **Development**            | Transforms a technical concept, principle, or design into a functioning technical solution.                                                | Functioning technical solution                      |
|                               | **Prototyping**            | Constructs an initial or experimental instance of a technical solution for examination and refinement.                                     | Prototype                                           |
|                               | **Optimization**           | Systematically modifies a technical solution to improve selected performance, cost, efficiency, reliability, or other properties.          | Improved technical solution                         |
| **Technical Qualification**   | **Verification**           | Establishes that a technical implementation conforms to specified requirements and design.                                                 | Verified conformity                                 |
|                               | **Validation**             | Establishes that a technical solution performs its intended function under its intended conditions of use.                                 | Validated solution                                  |
|                               | **Reliability Assessment** | Determines the ability of a technical solution to maintain required performance over time and under specified conditions.                  | Reliability evidence/estimate                       |
|                               | **Qualification**          | Establishes that a technical solution satisfies the requirements for a defined operational application.                                    | Qualified technical solution                        |
| **Technical Realization**     | **Scaling**                | Extends a technical solution to the required magnitude of capacity, volume, throughput, size, or deployment.                               | Scaled technical capability                         |
|                               | **Industrialization**      | Establishes the processes, infrastructure, organization, and controls required for repeatable production or deployment.                    | Reproducible production/deployment capability       |
|                               | **Integration**            | Incorporates a technical solution into a larger technical system while establishing required interfaces and interactions.                  | Integrated technical system                         |
|                               | **Deployment**             | Installs, configures, and brings a technical solution into its intended operational environment.                                           | Operationally deployed system                       |
| **Technical Operation**       | **Operation**              | Uses a technical system to perform its intended technical function under actual operating conditions.                                      | Performed technical function                        |
|                               | **Maintenance**            | Preserves or restores the required functional condition of a technical system throughout its operating life.                               | Sustained technical capability                      |
|                               | **Improvement**            | Modifies an existing operational technical system to improve its performance, capability, efficiency, reliability, or other properties.    | Improved operational system                         |
| **Technical Acquisition**     | **Acquisition**            | Identifies and obtains externally developed technical knowledge, technology, equipment, methods, processes, or know-how.                   | Acquired technical asset/capability                 |
|                               | **Transfer**               | Moves technical knowledge, technology, equipment, methods, processes, or know-how from one actor or context to another.                    | Transferred technical capability                    |
| **Technical Assimilation**    | **Assimilation**           | Develops sufficient understanding and practical capability to use and reproduce an acquired technology.                                    | Usable internal capability                          |
|                               | **Adaptation**             | Modifies an acquired technology to function effectively under different environmental, operational, institutional, or resource conditions. | Adapted technology                                  |
|                               | **Reproduction**           | Independently reproduces the essential technical structure and functionality of an acquired technology.                                    | Independently reproducible technology               |
| **Technical Mastery**         | **Mastery**                | Establishes independent capability to operate, maintain, reproduce, modify, troubleshoot, and improve a technology.                        | Independent technical mastery                       |
|                               | **Extension**              | Extends a mastered technology into new applications, configurations, operating domains, or technical capabilities.                         | Extended technical capability                       |
|                               | **Capability Development** | Uses accumulated technical knowledge and mastery to develop new independent technical capabilities and technologies.                       | New endogenous technical capability                 |
