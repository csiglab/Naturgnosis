Atlas of Public Organization Comparative Representation Systems.

A set of comparative representation systems for comparing public organizations across polities and periods — each system states its own universe, purpose, and version, and is a set of characteristic elements, each with its value set and assignment rule: assign one value per element and you have the comparative profile of a concrete instance. The systems name no verdicts; evaluation uses the elements, never a single rank. Sixteen sample organizations stand compared in Public Organizations Compared. Canonical tables live in the Public Organization note; this atlas is an explorer, not a fork.
