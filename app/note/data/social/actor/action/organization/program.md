# Program

> **Program** is the coordinated set of projects pursued under one objective — the organization form that binds separately managed efforts (projects, workflows, schedules) into a single commitment with one objective, one budget envelope, and one governance.

## Formulation

### What social element type does this social instance belong to?

**Program belongs to the `Program` social element type (Action category, `Action Organization` branch, Ontic layer)** — an organized set of projects existing extra-mentally as chartered efforts with staff, budgets, and deliverables. It is distinct from `Project` (a single time-bounded effort it contains), from `Policy` (the course it executes), and from `Plan` (the arrangement sequencing any one of its parts).

### What is this social instance?

> The portfolio commitment: an objective declared, projects gathered under it, a program office holding them together, a budget binding them, and a governance deciding what the set jointly delivers. Programs decompose into their kinds and their anatomy; the set is the instance, the envelope the form.

### What is the recursive instance decomposition of this social instance?

> Boundary: one organization family, decomposed at middle depth — kinds and anatomy only.
>
> Stopping rule: a row is terminal when it names a program kind or an anatomy element.
