# SWE Productivity

> **SWE Productivity** formulates software-engineering productivity methods and tools for development throughput. Source: Produceologia `docs/Production/Industry/Software/Firm/Productivity.md` (read-only import; the original is untouched).

## Formulation

### What epistemic element type does this epistemic instance belong to?

**SWE Productivity belongs to the `Epistemic Activity (Process)` epistemic element type — ordered tool applications forming a measurement-and-improvement process.**

### What is this epistemic instance?

> Methods and tools measuring and lifting software throughput: what to count, which tools observe it, and how teams convert observations into faster delivery.
