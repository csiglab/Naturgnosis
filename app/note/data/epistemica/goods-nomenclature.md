# Goods Nomenclature

> **Goods Nomenclature** sets good-naming criteria with a goods-classification list for comparable product naming. Source: Produceologia `docs/Toolkit/Data/Nomenclature.md` (read-only import; the original is untouched).

## Formulation

### What epistemic element type does this epistemic instance belong to?

**Goods Nomenclature belongs to the `Epistemic Standard` epistemic element type — normative criteria judging descriptions.**

### What is this epistemic instance?

> Naming criteria (distinctness, stability, comparability) applied over the goods list so product nodes across batches stay comparable.
