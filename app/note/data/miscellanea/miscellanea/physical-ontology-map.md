## Index

## Segmentation

> How to segment—or observed—physical reality in order to represent it?
>

| **Term** | **Description** | **Modeling Implications** |
| --- | --- | --- |
| **System** | A bounded set of interacting components with defined relations. | Requires defining boundaries, inputs/outputs, feedback loops; suitable for causal and dynamic modeling. |
| **Ecosystem** | A system of interacting entities within an environment, emphasizing interdependence. | Focus on flows, interactions, resilience, and emergent behaviors; boundaries are semi-permeable. |
| **Network** | A set of nodes and edges representing relationships or interactions. | Emphasizes topology, connectivity, centrality, and diffusion; can abstract from physical or material structure. |
| **Phenomenon** | An observable event, process, or occurrence. | Focused on patterns, correlations, and temporal dynamics; ideal when causality is complex or partially unknown. |
| **Process** | A sequence of events or state changes with causal continuity. | Supports dynamic modeling, temporal analysis, and prediction of system evolution; can be decomposed into subprocesses. |
| **Structure** | The arrangement or organization of components within a system. | Guides static or relational modeling; identifies constraints, hierarchies, and symmetries that shape system behavior. |

## Minimal Physical Ontology

> Let’s develop  a minimal physical ontology.
>

| Category | Description | Instance(s) |
| --- | --- | --- |
| **Entity** | Fundamental “thing” in the physical world, a bearer of properties | Electron, Proton, Photon, Particle, Rigid body, Object, Mass point, Continuous Media,  Ensembles, Quasiparticle |
| **Phenomena** | Observable occurrences arising from interactions | Electromagnetism, Gravity, Superconductivity, Drag, Collision, Momentum transfer, Energy transfer |
| **Process** | Sequence of events with causal continuity | Nuclear decay, Chemical reaction, Thermal conduction, Impulse, Work, Energy conservation, Mass transfer, **Motion** |
| **System** | A set of interacting entities considered as a whole | Solar System, Atomic nucleus, Plasma cloud, Continuous system, Rigid body system, Multi-body system |
| **Open System** | System exchanging matter or energy with the environment | Earth’s atmosphere, Engine combustion chamber, Engine system, Flow system |
| **Particle** | Discrete localized entity with intrinsic properties | Electron, Quark, Neutrino, Point mass, Particle in motion |
| **Field** | A spatially extended entity describing potential influence on particles | Electromagnetic field, Gravitational field, Force field (implicit in Newton’s Laws) |
| **Force (Interaction)** | A causal influence producing acceleration or change in motion | Gravity, Electromagnetic force, Weak nuclear force, Drag force, Contact force, Centripetal force |
| **Event** | Localized occurrence in spacetime | Photon absorption, Collision, Decay, Impulse application, Momentum exchange |
| **Quasiparticle** | Emergent particle-like excitation in a medium | Phonon, Exciton, Magnon |
| **Energy** | Quantitative measure of ability to perform work or cause change | Kinetic energy, Potential energy, Thermal energy, Work |
| **Space** | The relational “arena” where entities exist and interact | 3D Euclidean space, Minkowski spacetime, Constrained space (circular motion, rolling) |
| **Observable** | Measurable aspect of a system | Position, Momentum, Temperature, Velocity, Acceleration, Angular momentum |
| **Property** | Attribute or quality that an entity possesses | Charge, Spin, Mass, Color charge, Velocity, Angular velocity, Moment of inertia |
| **State** | Complete set of properties and observables describing a system at an instant | … |
| Property | Attribute or quality that an entity possesses | Charge, Spin, Mass, Color charge, Velocity, Angular velocity, Moment of inertia |
| Relation | Connections or dependencies between entities or observables | Gravitational coupling, Electromagnetic interaction, Constraint relations (hinge, rope, rolling) |
