Burstiness Index

live note interactive #diagnostic #temporal #distributional

In this note, we analyze one event stream through a single dimensionless measure — the burstiness index — that turns qualitative impressions of clustering into a comparable number.

Formulation

What epistemic element type does this instance belong to?

Concrete Epistemic Artifact — a computed claim about one event stream — produced by applying an Epistemic Operator (the B formula), and usable as an Epistemic Standard (regime classification). Schema: Philosophia Artium Epistemicarum et Operis.

What is this epistemic instance?

B = (σ−μ)/(σ+μ) over inter-event intervals, mapping any stream to [−1, 1]: −1 fully regular, 0 Poisson, +1 extremely bursty. Type: Descriptive Statistic — a temporal structure characterization tool within the epistemic toolbox.

What grounds this reading?

It resolves the epistemic gap of temporal pattern quantification — transforming qualitative observations of clustering into precise, comparable measurements. It preserves relative variance (coefficient of variation) and interval ordering; it destroys absolute timing (specific timestamps) and distribution shape (higher moments).

Diagnostic questions

What happens if assumptions are violated?

If temporal ordering is lost (events shuffled), B becomes meaningless — it measures a property that no longer exists. If simultaneous events occur, they must be handled (excluded or jittered) to avoid zero intervals.

What invariant does this tool rely on most critically?

The relationship between mean and variance — specifically that the coefficient of variation (σ/μ) captures meaningful temporal structure. This assumes intervals are i.i.d. samples from some underlying distribution.

Can two different tools produce indistinguishable artifacts?

Yes. A bimodal distribution (many short intervals, few very long intervals) and a power-law distribution can both yield B ≈ 0.7, yet represent fundamentally different temporal processes. B alone cannot distinguish them.

How robust is B to outliers?

Not robust. A single extremely long interval dramatically increases σ while barely affecting μ, pushing B toward +1. Consider using robust alternatives (median-based) or trimming extreme intervals.
