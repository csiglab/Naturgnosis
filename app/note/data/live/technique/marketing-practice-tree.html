How to read this tree

Each node is one row of the decomposition table: the label is the last segment of its Instance Tree Path, the color is its Technical Category. In the sunburst, rings follow depth and arc width follows subtree size, starting collapsed to depth 1. Click any arc with children to collapse or expand its subtree. Terminal rows — named tools, files, config attributes, measured values, named actors — are leaves. Deployment-specific values and named vendors appear only in exemplar rows.

The treemap shows the same tree with rectangle area proportional to subtree node count. Technique atlas groups the 31 imported technique families (area by family size; click to drill into method groups); Practice ensemble groups the original demand-generation subtree the same way. Clicking a leaf selects it in the panel; search dims non-matches but never navigates. The treemap ignores sunburst collapse state.
