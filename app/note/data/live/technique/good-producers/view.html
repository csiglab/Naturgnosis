Good-Producing Technical Element Catalog

Market-offered types of technical elements whose primary function is to transform reality itself, yielding a Good, organised by the kind of Good they deliver and their implement role. Generated from the Good-Producing Technical Element branch of Philosophia Artium Technicarum et Operis.

The test. An element is a producer when the transformation is the delivered Good. A conveyor that relocates goods it delivers is a producer (material/service good); the same belt moving another producer's output to the next station is a support implement, not a producer. Kinds: material, energy, information, service. Roles: machine, equipment, tool, facility, instrument, system.
