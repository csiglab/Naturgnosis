Formulation

What epistemic element type does this instance belong to?

Concrete Epistemic Artifact — a probabilistic model of one temporal event sequence — produced by applying an Epistemic Operator (the Hawkes intensity with exponential kernel), and usable as an Epistemic Standard (stationarity and residual checks). Schema: Philosophia Artium Epistemicarum et Operis.

What is this epistemic instance?

A self-exciting point process with base intensity μ, excitation α, and decay β: each event adds α to the intensity, decaying at rate β. Type: Generative / Inferential probability model — a temporal structure discovery tool within the epistemic toolbox.

What grounds this reading?

It resolves the epistemic gap of temporal structure discovery — distinguishing endogenous dynamics (self-excitation) from exogenous factors (background rate). It preserves temporal order, event count, and clustering degree; it destroys individual causality and inhibition effects.

Diagnostic Questions

What happens if branching ratio exceeds 1?

Explosive regime: intensity grows without bound, infinite events in finite time. Estimation methods fail.

What invariant is most critical?

Exponential decay structure — encodes proportional influence decay. Violations require kernel modifications.

Can different parameters produce indistinguishable sequences?

Yes — identifiability issues when long-run mean intensity λ̄ = μ/(1-n) is similar across parameter sets.
