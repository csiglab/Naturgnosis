# Decision-Maker

> Decision = f(Preferences, Beliefs, Perception, Emotion, Constraints, Social Context, Memory, Learning)
>

## Factor

| **Category** | **Factor** | **Description** | **Instance(s)** |
| --- | --- | --- | --- |
| **Goals & Preferences** | Utility / Value Function | What outcomes are desirable or valuable | Maximize profit, minimize pain, fairness |
|  | Priorities / Goals | Hierarchy or tradeoff between competing objectives | Health > convenience; speed vs. accuracy |
|  | Preferences | Subjective ordering of outcomes or states | Prefers chocolate to vanilla; risk-averse |
| **Beliefs & Information** | Belief State | Mental representation of the world, possibly uncertain | "This product is reliable"; Bayesian beliefs |
|  | Knowledge | Factual or experiential information held with certainty | Knows how a tool works, past experience |
|  | Information Access | What data is observable in the current context | Product labels, visible outcomes |
| **Cognitive Architecture** | Working Memory | Capacity to temporarily store and process information | Can compare 2–3 options at once |
|  | Attention | What is being focused on or ignored | Focused on price tag, distracted by noise |
|  | Heuristics / Rules | Simplified decision strategies or mental shortcuts | "Choose the cheapest"; availability bias |
|  | Reasoning Style | Analytical (slow) vs. intuitive (fast) thinking | Logical calculation vs. gut feeling |
| **Affective & Motivational States** | Emotion | Feelings that color evaluation of options | Fear, anger, joy |
|  | Stress / Arousal | Physiological state affecting speed/accuracy | Panic, deadline pressure, alertness |
|  | Motivation | Drives or needs energizing behavior | Hunger, achievement, affiliation |
| **Incentive Structure** | Rewards | Positive outcomes that increase likelihood of repeated behavior | Bonuses, praise, food, social approval |
|  | Punishments | Negative consequences that discourage behaviors | Fines, criticism, pain, social disapproval |
|  | Feedback Mechanisms | Information about outcomes that guide future decisions | Performance reviews, scoreboards, trial & error |
|  | Alignment of Incentives | How well incentives align with agent’s or system goals | Sales commission aligned with company profit |
|  | Intrinsic vs Extrinsic | Internal motivation vs external rewards or punishments | Enjoyment of task vs paycheck |
|  | Temporal Structure | Timing and frequency of incentives | Immediate reward vs delayed gratification |
| **Social & Cultural Context** | Norms & Expectations | Socially accepted or expected behavior | "Don’t cut in line", reciprocity norm |
|  | Roles & Identity | Socially defined roles or self-concept | "As a parent…", "As a manager…" |
|  | Cultural Schema | Internalized systems of meaning, values, metaphors | Collectivism, honor, independence |
| **Constraints** | Cognitive Constraints | Processing limits (attention, time, capacity) | Can’t compute all possibilities, fatigue |
|  | Environmental Constraints | Limits from the external world | No Wi-Fi, low light, limited options |
|  | Resource Constraints | Time, energy, money, computational power | 30 seconds to decide, limited budget |
| **Learning & Experience** | Reinforcement History | Past consequences shaping future choices | Avoids foods that caused nausea |
|  | Observational Learning | Learning from observing others’ decisions | "They succeeded by doing X" |
|  | Skill / Expertise | Accumulated competence and efficiency | Expert chess player, trained operator |
