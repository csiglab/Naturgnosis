# Cognitive Architecture

**Effective Frameworks: Cognitive Architectures**

| **Name** | **Description** | **Key Features** | **Domain** |
| --- | --- | --- | --- |
| **ACT-R** | Adaptive Control of Thought–Rational: simulates human cognition using symbolic and subsymbolic processes. | Declarative/procedural memory, production rules, modular subsystems. | Psychology, HCI, education |
| **Soar** | General cognitive architecture for problem-solving and learning. | Universal subgoaling, chunking (learning), symbolic representation. | Cognitive modeling, robotics |
| **Sigma** | Unified architecture combining logic, probability, and utilities. | Graphical models, decision-theoretic foundations, generality. | Cognitive modeling, AI |
| **CLARION** | Dual-process model: implicit and explicit processes. | Bottom-up learning, neural-symbolic integration. | Skill learning, decision making |
| **LIDA** | Learning Intelligent Distribution Agent: inspired by Global Workspace Theory. | Attention, episodic memory, consciousness modeling. | Cognitive neuroscience, AI |
| **OpenCog** | Cognitive architecture for AGI (Artificial General Intelligence). | AtomSpace (hypergraph), probabilistic logic, pattern mining. | AGI, robotics, language processing |
| **Leabra** | Local, Error-driven and Associative, Biologically Realistic Algorithm. | Neural networks with biological realism; integrates Hebbian and error-driven learning. | Computational neuroscience |
| **Spaun (Nengo)** | Large-scale brain model with neural architecture based on the Semantic Pointer Architecture. | Simulates visual input, memory, decision-making with spiking neurons. | Neuroscience, systems modeling |
| **AERA** | Autonomous, Self-improving Cognitive Architecture. | Self-modifying models and learning through simulation. | Machine learning, AGI |
