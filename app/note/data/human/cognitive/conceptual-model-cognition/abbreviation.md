# Abbreviation

> …
>

Aquí tienes la tabla actualizada con un ejemplo para cada tipo de abreviación:

| **Tipo de abreviación** | **Uso** | **Ejemplo** |
| --- | --- | --- |
| **Abreviaturas** | Se utilizan para acortar palabras en contextos formales e informales. | Sr. (Señor) |
| **Siglas** | Representan instituciones, organizaciones, y conceptos largos. | ONU (Organización de las Naciones Unidas) |
| **Acrónimos** | Nombres formados por las primeras letras o sílabas de varias palabras. | PYME (Pequeña y Mediana Empresa) |
| **Abreviaciones por truncamiento** | Se emplean para simplificar palabras truncándolas (dejando las primeras letras). | pág. (página) |
| **Contracciones** | Combinan partes de palabras para ahorrar espacio en la escritura. | Ud. (Usted) |
| **Monedas y unidades** | Usadas en economía, ciencia y comercio para representar divisas y medidas. | USD (Dólar estadounidense) |
| **Notas** | Para resumir o evitar enumeraciones largas, en textos o conversaciones. | etc. (Etcétera) |
