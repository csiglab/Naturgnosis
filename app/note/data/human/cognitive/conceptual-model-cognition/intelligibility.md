# Intelligibility

> In this note we will explore the concept of Intelligibility (*comprehensibility*): the degree to which a segment of reality can be represented in a form that enables it to be understood.
>

> **Intelligibility** can be decomposed in terms of the **segment of reality being understood** and the **cognitive representation** through which the **cognitive system grasps that reality**. Since we cannot change the segment of reality itself, the variable we can control is the **representation** through which we apprehend it. **Representations are therefore the means by which we make reality intelligible.**
>

## What makes some representations more effective than others at making a given segment of reality intelligible?

> **Note:** Understanding a segment of reality essentially means being able to identify and represent regularities in both its **structure** and its **dynamics**.
>

| Aspect | Description |
| --- | --- |
| **Fidelity** | How accurately the representation corresponds to the relevant structure or properties of the segment of reality. |
| **Relevance** | How well it captures the aspects of reality that matter for the purpose of understanding. |
| **Resolution** | The level of detail with which the relevant aspects of reality are represented. |
| **Clarity** | How easily the represented information can be distinguished and interpreted. |
| **Simplicity** | How economically the representation captures the relevant structure without unnecessary complexity. |
| **Structure** | How well the representation exposes relationships, dependencies, and organization within the represented reality. |
| **Consistency** | Whether the representation applies its symbols, rules, and relationships coherently. |
| **Compositionality** | Whether complex representations can be constructed from simpler representational elements while preserving meaning. |
| **Expressiveness** | The range of properties, relationships, and distinctions that the representation can express. |
| **Predictive power** | How well the representation allows the cognitive system to infer or anticipate aspects of the represented reality. |
| **Manipulability** | How easily the representation can be transformed or operated on to reveal information about the represented reality. |
| **Cognitive accessibility** | How readily the representation can be processed and understood by the cognitive system. |
| **Contextuality** | How well the representation incorporates the context necessary for interpreting the represented reality. |
| **Purpose fitness** | How well the representation serves the particular cognitive task for which the reality is being understood.\ |
