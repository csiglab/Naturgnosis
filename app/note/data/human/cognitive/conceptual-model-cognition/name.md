# Name

> A name is a **symbolic label that anchors a mental representation** to an **object**, concept, or category, enabling identification, communication, and cognitive manipulation.
>

> A **name is a tag or label** for a mental representation of something.
>

> A **name** can also function merely as an identifier for an object, serving only a communicative or identificational role; however, this conception of a name is not the one of interest in cognitive science.
>

> **Note:** Names (or tags) for **mental representations** are what allow us to truly become conscious of them, to **gain control over them (really just** 😊 **project understanding onto reality)**, and, consequently, to project that understanding onto reality.
>

> Aka. Cognitive Handle.
>

## Index

## Term

> What are the definitions of the term “Name” across fields?
>

| Field | Definition |
| --- | --- |
| **Philosophy / Linguistics** | A **proper name** is a word or expression that designates a particular entity without describing it. (Kripke, Frege) |
| **Cognitive Science / Psychology** | A name is a mental label linking a concept to a symbolic token, supporting identification, memory, categorization, and reasoning. |
| **Computer Science / Knowledge Representation** | A name is an identifier that uniquely references an object or entity within a formal or computational system. |
| **Social / Anthropological** | A name is a marker of identity, social role, or cultural categorization, used in communication and social interaction. |
| **Semiotics** | A name is a sign that represents a referent within a system of signs, carrying both denotative and connotative meaning. |

## Formulation

> What is a name in Cognitive Science?
>

A **name** is a cognitive token or symbol that:

1. Represents a specific object, concept, or category.
2. Enables conscious recognition and differentiation.
3. Supports abstraction, reasoning, and communication.
4. Can be treated as a **meta-representation**: a representation of an internal mental model.

## Role

> What is the role of a name in cognition?
>
- **Identification:** Distinguish one entity from another.
- **Categorization:** Group similar entities under shared labels.
- **Communication:** Share mental representations with others.
- **Abstraction:** Enable thought about concepts independent of immediate perception.
- **Consciousness link:** Anchors attention and awareness to a specific referent.

## Type

> Which are the  type of (names) (words) cognitive handles targets? Or What’s being handled?
>

> See more in [Type (Mental Representation Construct)](note.html?n=human/cognitive/conceptual-model-cognition/representation.md);  this is just a basic list.
>

| **Type** | **Description** | **Tags** |
| --- | --- | --- |
| **Proper Name** | Refers to a unique individual entity; rigid reference independent of descriptive content. | Unique, Singular, Rigid, Referential |
| **Common/Improper Name** | Refers to a class, category, or property; reference depends on descriptive content. | General, Predicate, Descriptive, Non-unique |
| **Definite Description** | A phrase that picks out a specific entity by description. Example: “the current president of the USA.” | Context-dependent, Descriptive, Referential |
| **Indefinite Description** | A phrase that refers to some member of a class without specifying which. Example: “a philosopher.” | Non-specific, Quantified, Predicate |
| **Functional Name** | Refers via a role or function rather than identity. Example: “CEO of Tesla.” | Role-based, Contextual, Non-rigid |
| **Conceptual Label** | Abstract term used to categorize phenomena; may carry semantic or ideological baggage. Example: “Industrial Policy.” | Abstract, Loaded, Analytical, Improper |
| **Metonymic Name** | Refers to something by association rather than direct identity. Example: “Hollywood” for the U.S. film industry. | Associative, Indirect, Cultural |
| **Proper Common Hybrid** | Terms that straddle proper and common usage, depending on context. Example: “Amazon” (company vs river). | Ambiguous, Context-sensitive, Polysemous |

## Definition

> See more in [Definition](https://app.notion.com/p/Definition-267c0f5171ec80b48078e5f6ff6f6af3?pvs=21).
>

> What is a definition? How word works in definitions?
>

> A **definition** is a formal operation within a representational system that establishes a *mapping* between a **definiendum** (the symbol, sign, or linguistic/conceptual entity to be defined) and a **definiens** (the structured set of terms, rules, or primitives already available within the system).
>

> How word works in definitions?  Words function as the building blocks of definitions. To internalize a definition, one must already possess **mental representations** of the words that constitute it. In other words, comprehension of a definition relies on prior knowledge or internalization of its component words.
>

## Property

> What are the properties of a good cognitive handle (name) (word)?
>

| **Property** | **Description** | **Case(s)** |
| --- | --- | --- |
| Concise | Short and easy to remember | “Blegg” for blue eggs |
| Descriptive | Evokes the concept or category it represents | “Rubes” for red cubes |
| Distinctive | Clearly differentiates from other handles | Avoid overlap with unrelated categories |
| Intuitive | Easy to infer meaning from context | “Tiger” for a large striped feline object |
| Flexible | Can accommodate small variations in instances | Handles slightly different shades or forms |
| Etimology Consistency | Root, prefix, or suffix aligns with established naming conventions; preserves semantic connections across related handles | “Blegg” and “Rube” share the suffix pattern for color-coded objects |
| Composable | Can be combined with other handles to create new ones | “Blue+Egg → Blegg”, “Red+Cube → Rubes” |
| Scalable | Works as the category grows or splits | Can handle dozens of variations without confusion |
| Mnemonic | Easy to recall or associate mentally | “Blegg” evokes “blue egg” directly in sound or spelling |
| Semantic Transparency | Meaning can be understood without prior exposure | “Rubes” clearly indicates red cubes |
| Avoids Ambiguity | Minimizes potential confusion with other categories or meanings | “Blegg” avoids being misread as “black egg” |

## Pitfalls

> What are the errors in choosing a cognitive handle (name or word)?
>

| **Pitfall** | **Description** | **Case(s)** |
| --- | --- | --- |
| Empty Word | No meaningful connection to the concept | Arbitrary letters like “XQF” |
| Ambiguous | Could refer to multiple categories | “Blue” could refer to any blue object |
| Overly Complex | Hard to remember or use | Long compound names |
| Misleading | Suggests incorrect properties | Calling a red cube a “blegg” |
| Too Narrow | Fails to generalize across similar instances | Name only works for one specific egg |

## Related

> Which are the related concepts?
>
- **Reference** – the link between a name and what it denotes.
- **Concept** – the mental representation associated with a name.
- **Symbol** – the token or sign used to express a name.
- **Meta-representation** – thinking about or labeling one’s own representations.
- **Language / Lexicon** – system of names and words within which the name operates.
