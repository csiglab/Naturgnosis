## Taxonomy

| **Purpose** | **Method / Technique** | **Year (Approx.)** | **Description** | **Example Applications** |
| --- | --- | --- | --- | --- |
| **Composition Analysis** | Combustion Analysis | ~1785 (Lavoisier) | Determines elemental composition (C, H, N, S). | Food, fuels, organic molecules |
|  | Gravimetric Analysis | ~17th–18th century | Measures mass of a compound or product to determine quantity. | Precipitate mass in water analysis |
|  | Titration | ~18th century (François Antoine Henri Descroizilles) | Uses a known reagent to determine unknown concentration via stoichiometry. | Water hardness, acid/base content |
|  | Elemental Analysis (CHNS) | ~1830s (Liebig, Dumas) | Quantifies individual elements in a sample. | Soil, metal alloys, biological samples |
|  | ICP-MS (Inductively Coupled Plasma Mass Spectrometry) | 1980s | High-sensitivity elemental analysis. | Trace metals, environmental monitoring |
| **Structure Determination** | Infrared (IR) Spectroscopy | ~1900s (Coblentz, Abney) | Analyzes molecular vibrations to infer functional groups. | Organic compounds, polymers |
|  | UV-Vis Spectroscopy | ~1940s | Measures electronic transitions in molecules. | Concentration analysis, reaction kinetics |
|  | Nuclear Magnetic Resonance (NMR) | 1946 (Bloch, Purcell) | Reveals molecular structure via nuclear spin interactions. | Organic chemistry, protein structure |
|  | Mass Spectrometry (MS) | 1912 (J.J. Thomson) | Identifies molecules by mass-to-charge ratio. | Drug discovery, metabolomics |
|  | X-ray Crystallography | 1912–1914 (von Laue, Braggs) | Reveals atomic arrangement in crystalline solids. | Protein folding, mineral structures |
| **Separation & Purification** | Chromatography (Paper, Column) | 1903 (Mikhail Tsvet) | Separates mixtures by physical or chemical properties. | Drug purity, plant compounds |
|  | Gas Chromatography (GC) | 1950s (James, Martin) | Separates volatile compounds. | Petrochemicals, environmental analysis |
|  | High-Performance Liquid Chromatography (HPLC) | 1960s–70s | High-resolution separation of non-volatile compounds. | Pharmaceuticals, biomolecules |
|  | Thin-Layer Chromatography (TLC) | 1938 (Izmailov, Shraiber) | Rapid separation of compounds on a plate. | Forensic analysis, organic synthesis |
|  | Centrifugation | 1864 (Antonin Prandtl) | Separates based on density by spinning samples. | Cell lysate fractionation, protein purification |
| **Reaction Observation** | Calorimetry | 1780s (Lavoisier, Laplace) | Measures heat flow in a chemical reaction. | Thermodynamics of reactions |
|  | Spectrophotometry | ~1940s | Measures light absorption over time to monitor reaction progress. | Enzyme kinetics, photoreactions |
|  | pH/Redox Monitoring | 1906 (pH electrode by Cremer; 1930s modern pH meter) | Observes acidity and oxidation state changes during reactions. | Soil analysis, fermentation monitoring |
| **Trace Detection / Monitoring** | Cyclic Voltammetry (CV) | ~1960s | Measures redox reactions via current-voltage curves. | Battery research, corrosion studies |
|  | Ion-Selective Electrodes (ISE) | ~1960s | Detects specific ions in solution. | Blood electrolytes, environmental monitoring |
|  | Fluorescence / Luminescence | ~1852 (Stokes) | Detects light emitted from excited molecules. | DNA staining, pollutant detection |
|  | Radiochemical Tracers | ~1913 (Hevesy) | Uses radioisotopes to track molecular pathways. | Metabolic studies, groundwater flow |
| **Environmental Sampling** | Passive Samplers | ~1970s | Collects airborne or waterborne molecules over time. | VOCs in air, pesticides in water |
|  | Soil/Water Sampling & Extraction | ~19th century | Gathers and extracts analytes from natural matrices. | Pollution studies, nutrient profiling |
| **Biochemical Methods** | Immunoassays (e.g., ELISA) | 1971 (Engvall, Perlmann) | Uses antibodies to detect biomolecules. | Pathogen detection, hormone quantification |
|  | Enzymatic Assays | ~19th–20th century | Monitors biochemical activities via substrate transformation. | Metabolism, food chemistry |
|  | DNA/RNA Sequencing | 1977 (Sanger, Maxam-Gilbert) | Identifies genetic material from organisms or environments. | Microbiome analysis, biodiversity studies |
