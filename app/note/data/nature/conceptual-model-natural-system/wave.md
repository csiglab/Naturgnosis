# Wave

> **Waves**: the study of the properties of locks, such as their frequency, wavelength, and amplitude
>

> **Note: In Spanish Onda.**
>

## Properties

| Term | Definition | Unit |
| --- | --- | --- |
| **Frequency (f)** | Number of complete **oscillations** or **cycles** that occur per unit of time | Hertz (Hz) = cycles per second (1/s) |
| **Period (T)** | Time it takes for one complete cycle or oscillation to occur | Seconds (s) |
| **Wavelength (λ)** | Distance between two consecutive points in phase on the wave (e.g., peak to peak) | Meters (m) |
| **Amplitude (A)** | Maximum displacement from the equilibrium or rest position | Depends on context (e.g., meters for displacement, volts for voltage) |
| **Wave Speed (v)** | How fast the wave propagates through the medium | meters per second (m/s) |
| **Phase** | The position within a cycle of the wave, often measured in degrees (0°–360°) or radians. Determines where in the oscillation the wave is at a given point in time. |  |
| **Smoothness & Regularity** | Differentiability and integrability properties of wave functions, studied in Sobolev spaces. |  |
