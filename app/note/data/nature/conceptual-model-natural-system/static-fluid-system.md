### 📘 **Taxonomy**

| **Category** | **Subcategory** | **Examples / Notes** |
| --- | --- | --- |
| **I. By Fluid Type** | Liquids – Incompressible | Water, oil |
|  | Liquids – Compressible | Mercury under high pressure |
|  | Gases – Ideal | Air at low pressure |
|  | Gases – Real | High-pressure gas in sealed container |
| **II. By System Configuration** | Open Systems | Open tank, manometer |
|  | Closed Systems | Pressurized vessel, sealed pipe |
|  | Semi-open Systems | U-tube with one sealed arm |
| **III. By Boundary Conditions** | Rigid Boundary | Steel tank, glass container |
|  | Deformable Boundary | Balloon, flexible membrane |
| **IV. By Pressure & Forces** | Uniform Pressure | Submerged body at constant depth |
|  | Gravitational Hydrostatics | Pressure increases with depth: $P = \rho g h$ |
|  | Externally Pressurized | Pressurized chambers, hydraulic cylinders |
| **V. By External Fields** | Gravitational Fields | Traditional hydrostatics |
|  | Accelerated Frames | Rotating tanks, elevators |
|  | Electromagnetic Fields | Ferrofluids, charged fluids at rest |
| **VI. By Functional Purpose** | Measurement | Barometer, manometer |
|  | Containment | Storage tank, pipeline |
|  | Load-Bearing | Hydraulic support, waterbed |
|  | Buoyancy | Submarines, floating bodies, hydrometers |
| **VII. By Theoretical Model** | Continuum Approximation | Macroscopic hydrostatics (e.g., fluid columns) |
|  | Statistical Mechanics | Microscopic gas pressure at rest |
|  | Finite Element / Discrete Models | Deformable boundaries, membrane-fluid interaction |
