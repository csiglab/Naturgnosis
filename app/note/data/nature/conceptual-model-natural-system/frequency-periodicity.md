# Frequency (Periodicity)

> **Frequency**: *The number of complete oscillations or cycles occurring per unit time, measured in Hertz (Hz).*
>

> **Oscillation**: *A repetitive back-and-forth movement around a central point or equilibrium position.*
>

> **Cycle**: *One complete sequence of a periodic process, from start to repetition (e.g., one full wave or rotation).*
>

## Modelling Tools

| **Category** | **Tool** | **Description** |
| --- | --- | --- |
| **Fourier Analysis** | Fourier Series | Breaks down periodic signals into sums of sine/cosine waves. |
|  | Fourier Transform | Converts time-domain signals to continuous frequency spectra. |
|  | Discrete Fourier Transform (DFT) | Analyzes sampled signals for frequency content (used in digital systems). |
| **Time-Frequency Analysis** | Short-Time Fourier Transform (STFT) | Tracks how frequencies change over time using sliding windows. |
|  | Wavelet Transform | Captures localized frequency details at different scales (good for transient signals). |
| **Dynamical Systems** | Floquet Theory | Studies solutions to differential equations with periodic coefficients. |
|  | Poincaré Map | Simplifies continuous periodic systems into discrete mappings. |
| **Spectral Methods** | Spectral Expansions | Solves PDEs using orthogonal basis functions (e.g., Fourier, Chebyshev). |
|  | Fast Fourier Transform (FFT) | Efficient algorithm for computing DFTs (used in simulations). |
| **Statistical Tools** | Power Spectral Density (PSD) | Measures energy distribution across frequencies in random signals. |
|  | Periodogram | Estimates PSD from time-series data. |
| **Algebraic Methods** | Spherical Harmonics | Decomposes functions on spherical surfaces (e.g., climate models). |
| **Numerical Tools** | Lomb-Scargle Periodogram | Detects periodic patterns in unevenly sampled data. |
|  | Autoregressive (AR) Models | Predicts future signal values based on past data (parametric approach). |

## **Measurement Units**

> Here's a concise table of **frequency measurement units** used across science and engineering:
>

| **Unit** | **Symbol** | **Definition** | **Application Field** |
| --- | --- | --- | --- |
| Hertz | Hz | 1 cycle per second | Physics, electronics, signal processing |
| Kilohertz | kHz | 10³ Hz | Radio, audio signals |
| Megahertz | MHz | 10⁶ Hz | Computer processors, radio waves |
| Gigahertz | GHz | 10⁹ Hz | Microwave, 5G networks |
| Terahertz | THz | 10¹² Hz | Infrared spectroscopy, astronomy |
| Revolutions per minute | RPM | 1 rotation per minute | Mechanical engines, hard drives |
| Radians per second | rad/s | 2π × Hz | Angular motion (e.g., motors) |
| Beats per minute | BPM | 1 beat per minute | Music tempo, heart rate |
| Cycles per minute | CPM | 1 oscillation per minute | Industrial vibration monitoring |
| Frames per second | fps | 1 image per second | Video, animation |

## Related Terms

> **Rate vs. Frequency**: "Rate" can describe non-periodic events (e.g., "error rate"), while "frequency" implies periodicity.
>

> **Pitch vs. Frequency**: Pitch is subjective (human perception), while frequency is objective (Hz).
>

| **Category** | **Synonyms/Related Terms** | **Description** |
| --- | --- | --- |
| **General** | **Rate** | How often an event occurs per unit time (e.g., "sampling rate"). |
|  | **Repetition** | Cyclic recurrence of an event. |
| **Physics** | Oscillation | Regular back-and-forth motion (e.g., pendulum). |
|  | Wavenumber (\(k\)) | Spatial frequency (cycles per unit distance). |
| **Signal Processing** | Spectral Density | Power per unit frequency (e.g., PSD). |
|  | Bandwidth | Range of frequencies in a signal. |
| **Wave Phenomena** | Pitch (Acoustics) | Perceived frequency of sound. |
|  | Wavelength (\(\lambda\)) | Inverse of spatial frequency (\(\lambda = c/f\)). |
| **Time Series** | Period (\(T\)) | Duration of one cycle (\(T = 1/f\)). |
|  | Cyclicity | Property of repeating at fixed intervals. |
| **Mathematics** | Eigenfrequency | Natural frequency of a system (from eigenvalues). |
| **Biology** | Rhythm | Regular biological cycles (e.g., circadian). |
| **Engineering** | Clock Speed | Frequency of a processor (Hz). |
