# Human Vision System

> The **Human Vision System (HVS)** is a complex biological and neurological system that processes light received by the eyes, converting it into electrical signals interpreted by the brain to perceive color, depth, motion, and spatial relationships.

## History

| **Time** | Work | **Authors** |
| --- | --- | --- |
| ~5th c. BCE | Theories of vision: extramission (eye emits rays) vs. intromission (light enters eye) | Plato, Democritus |
| ~300 BCE | Mathematical treatment of vision rays | Euclid |
| 2nd c. CE | Early description of eye structures (cornea, lens, retina, optic nerve) | Galen |
| 10th–11th c. | Vision explained as light entering the eye; experimental optics; camera obscura | Ibn al-Haytham (Alhazen) |
| 1200s | Integration of Alhazen’s optics into Western science | Roger Bacon |
| 1604 | Retinal image formation; image inversion | Johannes Kepler |
| 1625 | Pinhole experiments on retinal inversion | Christoph Scheiner |
| 1660s | Spectrum decomposition, color perception theories | Newton, Descartes |
| 1824 | Optic nerve function described | Charles Bell |
| 1830s | Doctrine of specific nerve energies | Johannes Müller |
| 1860 | Trichromatic theory; vision as unconscious inference | Hermann von Helmholtz |
| 1879 | Opponent-process theory | Ewald Hering |
| 1860s–1900s | Sensory thresholds, scaling laws | Fechner, Weber |
| 1920s–1930s | Discovery of rods and cones | Various histologists |
| 1941 | Lateral inhibition in retina | Haldan Hartline |
| 1959–1962 | Orientation-selective cortical cells; hierarchical processing | Hubel & Wiesel |
| 1982 | Vision as multi-stage information processing | David Marr |
| 1970s | Split-brain research, hemispheric specialization | Roger Sperry, Michael Gazzaniga |
| 1980s–1990s | Mapping of visual cortex with fMRI, PET | Multiple labs |
| 1990s–2000s | “What” (ventral) vs. “Where/How” (dorsal) streams | Ungerleider & Mishkin, Goodale & Milner |
| 2000s–present | Retinal coding, cortical circuits, visual hierarchy | Many labs worldwide |
| 2010s–2020s | Optogenetics, connectomics, deep learning models of vision | Deisseroth, Seung, others |
