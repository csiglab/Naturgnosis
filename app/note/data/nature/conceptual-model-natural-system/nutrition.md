# Nutrition

> **Nutrition** is the biological process by which organisms **take in, assimilate, and use food substances** to support growth, repair, energy production, and overall maintenance of life.
>
>
> It includes the ingestion, digestion, absorption, and metabolism of nutrients.
>

> **Note:** This is an integrative overview of both animal and plant nutrition. Specific subcategories exist for different species and environmental or physiological conditions.
>

## Animal Nutrition

> This note will be as general as possible for the Kingdom (Animalia)
>

| **Type** | **Nutrient** | **Sources** | **Biological Role** |
| --- | --- | --- | --- |
| Macronutrient | **Carbohydrates** | Grains, fruits, plant starches | Main energy source (glucose → ATP); stored as glycogen |
|  | **Proteins** | Meat, legumes, eggs, dairy, soy | Builds tissues, enzymes, hormones, immune molecules |
|  | **Lipids (Fats)** | Animal fat, oils, seeds, fish | Energy storage, cell membranes, insulation, vitamin absorption |
|  | **Water** | Drinking water, food moisture | Solvent, thermoregulation, transport, cellular processes |
| Vitamin (Fat-soluble) | **Vitamin A** | Liver, fish oil, leafy greens | Vision, immunity, skin and epithelium maintenance |
|  | **Vitamin D** | Sunlight, fish oil, fortified foods | Calcium absorption, bone development |
|  | **Vitamin E** | Vegetable oils, seeds, nuts | Antioxidant, membrane protection |
|  | **Vitamin K** | Leafy greens, gut microbiota | Blood clotting, bone metabolism |
| Vitamin (Water-soluble) | **Vitamin B1 (Thiamine)** | Whole grains, meat | Energy metabolism, nerve function |
|  | **Vitamin B2 (Riboflavin)** | Eggs, milk, meat | Cellular respiration, antioxidant protection |
|  | **Vitamin B6** | Meat, grains, vegetables | Amino acid metabolism, neurotransmitters |
|  | **Vitamin B12** | Meat, eggs, dairy | Red blood cell formation, DNA synthesis, nerve function |
|  | **Folate (B9)** | Leafy greens, legumes | DNA/RNA synthesis, fetal development |
|  | **Vitamin C** | Fruits (not essential in all animals) | Collagen synthesis, antioxidant, immune function |
| Mineral | **Calcium** | Dairy, bones, leafy greens | Bones/teeth, muscle contraction, nerve signaling |
|  | **Phosphorus** | Meat, dairy, grains | Bones, ATP production, nucleic acids |
|  | **Potassium** | Fruits, vegetables, meat | Fluid balance, nerve and muscle function |
|  | **Sodium** | Salt, processed feeds | Electrolyte balance, nerve impulses |
|  | **Magnesium** | Grains, green plants | Enzyme activity, muscle/nerve function, bone health |
|  | **Iron** | Red meat, organ meats, legumes | Oxygen transport (hemoglobin), enzymatic reactions |
|  | **Zinc** | Meat, seafood, whole grains | Enzymes, immune function, skin repair |
|  | **Iodine** | Iodized salt, seaweed | Thyroid hormone synthesis |
|  | **Selenium** | Grains, seafood, varies by soil | Antioxidant (glutathione peroxidase), thyroid function |

## Plant Nutrition

> …
>

| Nutrient | Source | Role in Plant Nutrition |
| --- | --- | --- |
| **Nitrogen (N)** | Soil organic matter (decomposed plants, compost, manure) | Building blocks of amino acids, proteins, enzymes, chlorophyll |
|  | Fertilizers (synthetic or organic) | Supplement nitrogen to promote leaf and stem growth |
|  | Soil microorganisms (nitrogen-fixing bacteria) | Convert atmospheric N₂ into plant-usable forms (ammonium, nitrate) |
| **Phosphorus (P)** | Soil organic matter | Important for energy transfer (ATP), root development |
|  | Fertilizers | Supplement phosphorus for energy metabolism and growth |
|  | Soil minerals (rock phosphate) | Slowly available phosphorus source |
| **Potassium (K)** | Soil minerals | Regulates osmotic balance, enzyme activation, water use |
|  | Fertilizers | Supplements potassium for stress resistance and fruit quality |
| **Calcium (Ca)** | Soil minerals | Cell wall structure, membrane stability |
|  | Fertilizers | Supplements calcium for cell growth |
| **Magnesium (Mg)** | Soil minerals | Central atom in chlorophyll, enzyme activator |
|  | Fertilizers | Supplements magnesium for photosynthesis |
| **Sulfur (S)** | Soil organic matter | Component of amino acids and vitamins |
|  | Fertilizers | Supplements sulfur for protein synthesis |
| **Micronutrients (Fe, Mn, Zn, Cu, B, Mo, Cl)** | Soil minerals and organic matter | Cofactors for enzymes, chlorophyll synthesis, hormone regulation |
|  | Fertilizers | Supplements trace elements needed in small amounts |
