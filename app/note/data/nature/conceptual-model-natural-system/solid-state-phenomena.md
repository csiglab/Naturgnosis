# Solid State Phenomena

> **Solid State Phenomena** refers to the physical properties and behaviors of solid materials, including their electronic, magnetic, optical, and structural characteristics, governed by the interactions of atoms and electrons within their crystalline or amorphous structures.

## Index

## Systems

> Solid-state physics studies **condensed matter systems** where atomic and electronic interactions give rise to emergent macroscopic properties. These include:
>

| **Category** | **Subcategory** | **Examples/Description** |
| --- | --- | --- |
| **Crystalline Solids** | **Metals** | Conductors with delocalized electrons (e.g., copper, aluminum). |
|  | **Semiconductors** | Materials with tunable electrical properties (e.g., silicon, gallium arsenide). |
|  | **Insulators** | Materials with a large electronic bandgap (e.g., quartz, diamond). |
|  | **Superconductors** | Materials exhibiting zero electrical resistance below a critical temperature (e.g., niobium, YBCO). |
| **Amorphous Solids** | **Glasses** | Disordered atomic arrangements with no long-range periodicity (e.g., silica glass). |
|  | **Polymers** | Long-chain molecular structures with diverse electronic and mechanical properties. |
| **Low-Dimensional Systems** | **Nanostructures** | Quantum dots, nanowires, and nanotubes with quantum confinement effects. |
|  | **2D Materials** | Monolayer materials like graphene, transition metal dichalcogenides (TMDs). |
|  | **Thin Films** | Nanoscale layered materials used in electronic and optical devices. |
| **Strongly Correlated Systems** | **Mott Insulators** | Materials where electron interactions prevent conductivity despite band theory predictions. |
|  | **Magnetic Materials** | Ferromagnets, antiferromagnets, and spintronic systems. |
|  | **Topological Insulators** | Materials with insulating bulk and conductive surface states protected by topology. |
| **Quasiparticle and Collective Excitation Systems** | **Phononic Systems** | Lattice vibrations and thermal transport mechanisms. |
|  | **Plasmonic Systems** | Collective charge oscillations in metals. |
|  | **Excitonic Systems** | Electron-hole bound states in semiconductors. |

## Frameworks

> Solid-state physics relies on several theoretical frameworks to describe and analyze the properties of solids. Here are the major ones:
>

| **Category** | **Model/Framework** | **Description** |
| --- | --- | --- |
| **Classical Models** | **Drude Model (1900)** | Describes electrical and thermal conductivity in metals using classical electron gas theory. |
|  | **Sommerfeld Free Electron Model (1928)** | Extends the Drude model by incorporating quantum statistics (Fermi-Dirac distribution). |
| **Quantum Mechanics-Based Frameworks** | **Band Theory of Solids (1930s)** | Explains electrical properties of materials via energy bands, derived from Bloch’s theorem and the Schrödinger equation. |
|  | **Tight-Binding Model** | Approximates electron wavefunctions in a crystal using atomic orbitals, useful for covalent solids. |
|  | **Density Functional Theory (DFT, 1964-1965)** | A quantum mechanical approach for calculating electronic structure and material properties. |
|  | **Many-Body Perturbation Theory (MBPT)** | Accounts for electron-electron interactions beyond DFT, using methods like GW approximation. |
|  | **Quantum Monte Carlo (QMC)** | Uses stochastic methods to solve many-body problems numerically. |
| **Lattice Dynamics and Phonon Models** | **Harmonic Approximation** | Treats atomic vibrations as harmonic oscillators to study phonons. |
|  | **Debye Model (1912)** | Approximates the phonon contribution to heat capacity. |
|  | **Born–von Kármán Theory** | Describes lattice vibrations using periodic boundary conditions. |
| **Strongly Correlated Electron Systems** | **Hubbard Model (1963)** | Describes electron interactions in transition metals and Mott insulators. |
|  | **Anderson Localization Theory (1958)** | Explains electron wavefunction localization in disordered systems. |
|  | **Dynamical Mean Field Theory (DMFT, 1990s)** | Solves strongly correlated electron systems using local self-energy approximations. |
| **Semiclassical Models** | **Boltzmann Transport Equation (1872, applied to solids in the 1930s)** | Describes charge and heat transport in semiconductors and metals. |
|  | **Kubo Formalism (1957)** | Uses linear response theory to compute conductivity and other transport coefficients. |
| **Topological and Modern Quantum Frameworks** | **Berry Phase and Topological Band Theory (1984)** | Underlies topological insulators and quantum Hall effects. |
|  | **Bogoliubov-de Gennes (BdG) Equations (1958)** | Describes superconductivity in the framework of BCS theory. |
