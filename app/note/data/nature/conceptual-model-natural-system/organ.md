# Organ

> An **organ** is made up of multiple types of tissues. These tissues make up an organ’s structure, and also work together.
>

### 🧍 Human Body

| **System** | **Organ** | **Primary Function** |
| --- | --- | --- |
| **Nervous** | Brain | Control center; processes sensory input and coordination |
|  | Spinal Cord | Transmits signals between brain and body |
|  | Nerves | Conduct electrical impulses throughout the body |
| **Circulatory** | Heart | Pumps blood throughout the body |
|  | Blood Vessels (Arteries, Veins) | Transport blood, oxygen, nutrients |
| **Respiratory** | Lungs | Gas exchange: oxygen in, carbon dioxide out |
|  | Trachea | Air passage to lungs |
|  | Bronchi | Branches leading to lungs |
| **Digestive** | Stomach | Breaks down food with acid and enzymes |
|  | Liver | Produces bile, detoxifies, regulates metabolism |
|  | Pancreas | Produces digestive enzymes and insulin |
|  | Small Intestine | Nutrient absorption |
|  | Large Intestine | Water absorption, waste processing |
|  | Esophagus | Transports food to stomach |
|  | Gallbladder | Stores and releases bile |
| **Excretory/Urinary** | Kidneys | Filter blood, produce urine |
|  | Ureters | Carry urine from kidneys to bladder |
|  | Bladder | Stores urine |
|  | Urethra | Releases urine from body |
| **Reproductive** | Ovaries (female) | Produce eggs and hormones |
|  | Uterus (female) | Supports fetal development |
|  | Testes (male) | Produce sperm and hormones |
|  | Penis (male) / Vagina (female) | Copulation, birth canal |
| **Endocrine** | Pituitary Gland | Master gland, controls other glands |
|  | Thyroid Gland | Regulates metabolism |
|  | Adrenal Glands | Regulate stress response |
|  | Pancreas (also endocrine) | Produces insulin and glucagon |
| **Immune/Lymphatic** | Spleen | Filters blood, recycles red cells |
|  | Thymus | Matures T-cells |
|  | Lymph Nodes | Filter lymph, fight infection |
| **Integumentary** | Skin | Barrier, temperature regulation |
|  | Hair | Protection, sensory |
|  | Nails | Protection |
| **Musculoskeletal** | Bones (e.g., femur, ribs, skull) | Support, movement, protection |
|  | Muscles | Movement, posture, heat generation |
|  | Joints | Allow flexibility and motion |
