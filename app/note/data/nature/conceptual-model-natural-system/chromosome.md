# Chromosome

> Each chromosome is a single, long DNA molecule tightly packed with proteins (histones) to form chromatin.
>

> The DNA in each chromosome is a **double-stranded helix** made up of nucleotides (adenine, thymine, cytosine, and guanine).
>
