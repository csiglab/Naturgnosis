# Gravitational System

> A general, neutral term referring to any collection of bodies interacting via gravity.
>

> "**N-body gravitational system**" is the most general and accepted technical term.
>

| **Term** | **Used When Referring To...** | **Notes** |
| --- | --- | --- |
| **N-body system** | Any system with N≥2N \geq 2 gravitationally interacting masses | General and widely used in physics and astronomy |
| **Dynamical system** | Any time-evolving system governed by deterministic laws (usually ODEs) | Used more mathematically; includes celestial systems |
| **Celestial system** | A bounded group of celestial objects (e.g. solar system, binary star) | Emphasizes astronomical context |
| **Astrodynamical system** | A system including man-made spacecraft and/or natural celestial bodies | Used in aerospace and space mission planning |
| **Orbital system** | A system with bodies in closed or open trajectories around each other | Emphasizes motion and orbital configuration |
| **Restricted N-body system** | A simplified system where one or more masses are assumed negligible | Common in analytical studies (e.g., restricted 3-body) |

## System Taxonomy

> …
>

| **Category** | **System Type** | **Case Study** | **Application** |
| --- | --- | --- | --- |
| **Natural Systems** | Two-body system | Earth–Moon, Sun–Mercury | Simplest analytical case, orbits follow conic sections |
|  | Three-body system | Sun–Earth–Moon, Alpha Centauri | Lagrange points, perturbations, tidal locking |
|  | Restricted three-body | Sun–Earth–Satellite (massless 3rd body) | Spacecraft mission design (e.g., JWST) |
|  | N-body system (N > 3) | Solar System, star clusters, galaxies | Requires numerical integration; chaotic dynamics |
|  | Planetary system | Solar System, exoplanetary systems | Includes planets, moons, rings |
|  | Binary/multiple stars | Alpha Centauri, Sirius A–B | Mass exchange, orbital decay |
|  | Natural satellite system | Earth–Moon, Jupiter–Galilean moons | Tidal interactions, orbital resonances |
|  | Asteroid/comet systems | Asteroid families, binaries | Gravitational aggregates, YORP effect |
|  | Galactic gravitational system | Spiral galaxies, galaxy clusters | Stellar orbits, dark matter inference |
|  | Black hole systems | Binary black holes, galactic centers | Extreme gravity, gravitational waves |
| **Engineered Systems** | Artificial satellite system | Earth–GPS constellation | Orbit design, station-keeping, attitude control |
|  | Satellite constellation / swarm | Starlink, Galileo | Coordinated multiple-satellite dynamics |
|  | Spacecraft–planet system | Cassini–Saturn, Voyager–Jupiter | Gravity assist, orbital insertion |
|  | Space tether systems | Tethered satellites, electrodynamic tethers | Exploit or counteract gravity using tension |
|  | Gravitational slingshot (assist) | Voyager missions, BepiColombo | Use planetary gravity to change spacecraft velocity |
|  | Station-keeping systems | Lagrange point missions (e.g., SOHO, JWST) | Maintain artificial equilibrium positions |
|  | Formation flying | Multi-spacecraft interferometry missions | Synthetic apertures, precision measurements |
|  | Space elevator dynamics | Theoretical Earth tether | Tension/gravity equilibrium, orbital mechanics |
|  | Orbital debris field | Defunct satellites, fragments | Collision modeling, gravitational evolution |
|  | Asteroid redirection | NASA DART, ESA Hera | Altering natural gravitational systems intentionally |
