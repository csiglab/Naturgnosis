# Agriculture Production

> **Agriculture Production** frames the sector-of-industries production across crop and animal subsectors, from banana plantations to beef feedlots. Source: Produceologia `docs/Production/Industry/Agriculture/` (read-only import; the originals are untouched).

## Formulation

### What technical element type does this technical instance belong to?

**Agriculture Production belongs to the `Production Technical System` technical element type — an organized set of objects realizing cultivation and rearing capability.**

### What is this technical instance?

> Banana product and organization starters with breeding-to-value-chain beef stages under sector-of-industries framing that separates industry analysis from market analysis.

### What is the recursive instance decomposition of this technical instance?
