# House System

> The **House System** is the house as a micro-environment technical system with a habitat schema, structure, functions, and object taxonomy. Source: Produceologia `docs/Production/Technique/Breviarium/House/` (read-only import; the original is untouched).

## Formulation

### What technical element type does this technical instance belong to?

**House System belongs to the `Production Technical System` technical element type — an organized set of objects realizing shelter capability.**

### What is this technical instance?

> Foundation, envelope, HVAC, plumbing, and electrical structure hosting cook, clean, rest, host, and work functions across a ten-class object taxonomy — with climatization, fan, wiring, and washer-dryer procedures attached.
