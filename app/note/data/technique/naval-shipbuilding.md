# Naval Shipbuilding

> **Naval Shipbuilding** covers commercial and military shipbuilding: propulsion, navigation, shipyard construction, and MRO. Source: Produceologia `docs/Production/Technique/Fisicatecnica/Mechanical/Naval/` (read-only import; the original is untouched).

## Formulation

### What technical element type does this technical instance belong to?

**Naval Shipbuilding belongs to the `Production Technical System` technical element type — an organized set of objects realizing maritime capability.**

### What is this technical instance?

> Commercial and military vessels with propulsion including nuclear options, radar and sonar suites, shipyard build processes, MRO cycles, and offshore-wind support roles.
