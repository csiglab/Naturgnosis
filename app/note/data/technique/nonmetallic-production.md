# Nonmetallic Production

> **Nonmetallic Production** is glass, cement, and ceramics production. Source: Produceologia `docs/Production/Industry/Nonmetallic/README.md` (read-only import; the original is untouched).

## Formulation

### What technical element type does this technical instance belong to?

**Nonmetallic Production belongs to the `Production Technical System` technical element type — an organized set of objects realizing nonmetallic-material capability.**

### What is this technical instance?

> Furnaces and kilns converting silica, limestone, and clays into glass, cement, and ceramic goods.
