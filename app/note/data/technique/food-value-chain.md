# Food Value Chain

> The **Food Value Chain** runs farm-to-consumption: inputs, production, harvest, processing, packaging, cold storage, distribution, retail, and waste. Source: Produceologia `docs/Production/Industry/Food/Food.md` (read-only import; the original is untouched).

## Formulation

### What technical element type does this technical instance belong to?

**Food Value Chain belongs to the `Production Technical System` technical element type — an organized set of objects realizing nourishment capability.**

### What is this technical instance?

> Raw, processed, beverage, ready, confectionery, health, baby, and pet markets across fifteen farming models from subsistence to vertical and regenerative, with precision agriculture, HPP, pasteurization, extrusion, fermentation, MAP, smart and biodegradable packaging, blockchain traceability, cold chains, and drones.

### What is the recursive instance decomposition of this technical instance?

> Boundary: one value chain, decomposed at shallow depth — root plus production, preservation, and distribution constituents only.
