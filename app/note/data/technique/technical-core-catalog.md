# Technical Core Catalog

> The **Technical Core Catalog** (PTCC) groups related technical objects — operational, constitutive, continuous, and production objects — into eight domains by core transformation principle. Source: Produceologia `docs/Production/Technique/Catalog/README.md` (read-only import; the original is untouched).

## Formulation

### What technical element type does this technical instance belong to?

**Technical Core Catalog belongs to the `Technical Element Set` technical element type — the generic composite scoping a coherent ensemble of technical elements.**

### What is this technical instance?

> The catalog's formulation: Technical Object (Constitutive Technique) — Constitutive Technique + Operating Technique → Products. Each domain pairs techniques and embedded objects with the capital goods that realize them and the products they yield.
