# Remote Sensing

> **Remote Sensing** is distance data-collection via satellite, airborne, drone, ground, and marine sensors across spectra. Source: Produceologia `docs/Production/Technique/Fisicatecnica/Electromagnetic/Remote-Sensing.md` (read-only import; the original is untouched).

## Formulation

### What technical element type does this technical instance belong to?

**Remote Sensing belongs to the `General Technique` technical element type — a generalized method for distance observation operations.**

### What is this technical instance?

> Optical, multispectral, and hyperspectral imaging (400–2500 nm), LiDAR altimetry, SAR and microwave sensing, thermal bands (3–14 µm), flown on Landsat, Sentinel, MODIS, GOES, and UAV platforms across agriculture, forestry, water, disaster, urban, and defense applications.
