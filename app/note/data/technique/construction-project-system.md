# Construction Project System

> The **Construction Project System** is project-based delivery of bespoke structures with delivery models, contracts, and lifecycle stages. Source: Produceologia `docs/Production/Industry/Construction/Construction.md` (read-only import; the original is untouched).

## Formulation

### What technical element type does this technical instance belong to?

**Construction Project System belongs to the `Production Technical System` technical element type — an organized set of objects and practices realizing built structures.**

### What is this technical instance?

> Product spaces from buildings and infra to fit-out, demolition, and recycling; firm axes across GC, specialty, design-build, and EPC with BIM and prefab capabilities and bid, turnkey, and cost-plus models; delivery frames (DBB, design-build, CM, EPC), contracts (lump, cost-plus, T&M, GMP), and pre-to-post lifecycles with cash, rework, and reputation loops.

### What is the recursive instance decomposition of this technical instance?

> Boundary: one project system, decomposed at shallow depth — root plus delivery, contract, model, and handover constituents only.
