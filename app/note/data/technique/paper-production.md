# Paper Production

> **Paper Production** is downstream paper, cardboard, and tissue production on upstream pulp. Source: Produceologia `docs/Production/Industry/Forest/Industry/Paper.md` and `docs/Production/Industry/Forest/README.md` (read-only import; the originals are untouched).

## Formulation

### What technical element type does this technical instance belong to?

**Paper Production belongs to the `Production Technical System` technical element type — an organized set of objects realizing paper-goods capability.**

### What is this technical instance?

> Pulp digesters feeding paper machines into tissue lines and cardboard plants, guided upstream by sector, stage, scale, and cost questions.

### What is the recursive instance decomposition of this technical instance?

> Boundary: one paper system, decomposed at shallow depth — root plus digester, machine, and plant constituents only.
>
