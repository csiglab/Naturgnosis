# Rubber Production

> **Rubber Production** covers hose, seal, belt, and mat rubber production. Source: Produceologia `docs/Production/Industry/Rubber/README.md` (read-only import; the original is untouched).

## Formulation

### What technical element type does this technical instance belong to?

**Rubber Production belongs to the `Production Technical System` technical element type — an organized set of objects realizing elastomer-goods capability.**

### What is this technical instance?

> Mixers through vulcanizers into belt lines and molded goods.

### What is the recursive instance decomposition of this technical instance?

> Boundary: one rubber system, decomposed at shallow depth — root plus mixing, curing, and line constituents only.
>
