# AGENTS.md — Phrases Catalog

## Purpose

Aphorisms, proverbs and locutions worth keeping, persisted as a CouchDB dataset (`dataset=phrases`)
with a searchable catalog and a small form editor. Spec: `spec/phrases/README.md`.

## Layout

- `web/index.html` — catalog (card grid + search); loads `/api/graph?dataset=phrases` with fallback
  to the static mirror.
- `web/edit.html` — list + form editor; saves via `POST /api/graph/save` (supports `delete_ids`).
- `data/data.json` — server-written mirror / seed (generated by `bin/import_phrases.py`).
- `import/` — raw Notion exports; archival.

## Commands

```sh
python bin/sync.py                        # serve + sync (dataset=phrases)
python bin/import_phrases.py              # one-shot seed from import/ (overwrites data.json)
python bin/seed_couchdb.py --dataset phrases
```

## Invariants

- Dataset id is `phrases`; nodes follow the Naturgnosis node model (`category: "Phrase"`).
- `data.json` is server-written or import-generated: never hand-edit.
- Deletions go through the editor → API (`delete_ids`), not by editing the mirror.
