# Glossary

> The vocabulary of Naturgnosis: terms of art across episteme and technique — ontology, methodology,
> economics, philosophy of science, engineering — with concise entries and pointers to sources.

## Storage model

- **Source of truth: physical markdown.** One file per term under `app/glossary/entries/`
  (`<Term>.md`; duplicates get `-2`, `-3` suffixes until manually merged).
- **Derived:** `app/glossary/data/index.json`, generated by `bin/build_glossary_index.py`
  (term, file, excerpt). The index is committed so the viewer works without any backend; rebuild and
  commit it after adding or renaming entries.
- **Not in CouchDB.** If a future requirement demands server-side search or editing, revisit — do not
  silently duplicate state.

Entry format (Notion-export compatible):

```markdown
# Term

> Definition paragraph(s)…

## References

- https://…
```

## UI

`app/glossary/web/index.html` — single page:

- **Entry index** — alphabetical list with letter groupings, from `index.json`.
- **Search** — client-side filter over term and excerpt.
- **Reader** — fetches `../entries/<file>` and renders minimal markdown
  (headings, blockquotes, lists, links, bold/italic/code) under the Oxford Common Room tokens
  (`/shared/theme.css`).

## Operations

```sh
python bin/build_glossary_index.py     # rebuild the index after editing entries
```

Imported raw exports (CSV provenance) live in `app/glossary/import/` — do not edit; they are archival.

## Conventions

- File name = term name (ASCII-safe where possible); spaces allowed, no Notion ids.
- Definitions live inside blockquotes; references as links in a `## References` section.
- English preferred; keep original-language terms as aliases in the body, not the file name.
